# Cape Town Fortnightly

What's on in Cape Town and the Winelands. Live at https://fortnightly.capetown/

This repository holds only the published page and is rewritten by the weekly pipeline; nothing is edited here by hand.
The page is one self-contained file. It lists public events gathered from venues' and organisers' own announcements,
their newsletters and Instagram, and the ticket sites, read and sorted by a language model. Each event links to the
organiser or ticket seller; the page republishes no descriptions or images.

Spotted a mistake? Email capetowneventstdw@gmail.com.
